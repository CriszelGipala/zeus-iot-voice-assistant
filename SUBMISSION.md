## Project Description
This project implements an IoT-based voice assistant running on a Raspberry Pi. The system listens for a wake phrase and processes spoken commands using offline speech recognition. It is capable of responding with audio output and interacting with external services such as sensors and cloud platforms. The project demonstrates the integration of hardware, software, and networking concepts commonly used in IoT systems.

## Tools, Technologies and Equipment
- Raspberry Pi  
- Python  
- Vosk (offline speech recognition)  
- SoundDevice (audio input/output)  
- USB Microphone and Speaker  
- Sense HAT (temperature and humidity sensing)  
- Blynk / ThingSpeak (for IoT communication and data handling)  
- GitHub for version control
